ヒント
Module Name: 生成されるDockerfileの対象となるロボットソフトウェアモジュールの名称です。（基本タブの設定値が使用されます）
Description: ロボットソフトウェアモジュールの概要記述です。（基本タブの設定値が使用されます）
Middleware: 使用するロボットミドルウェア（ROS 1, ROS 2, OpenRTMなど）を選択します。
Middleware Version: ミドルウェアのディストリビューション（Noetic, Humbleなど）を選択します。
OS Version: ベースイメージとなるOSのバージョンを選択します。
Workspace: コンテナ内に作成するワークスペースのディレクトリ名を入力します。（例: catkin_ws, colcon_ws）
Language: コンポーネントの開発に使用する主要言語（C++ または Python）を選択します。
Configuration: インストール構成を選択します。（Min: 最小構成 / Full: デスクトップ環境含む推奨構成 / Std: 標準）
Library Name: 追加インストールするライブラリの名称を入力します。（論理名を入力すると、生成時に適切なパッケージ名に変換されます）
URL: ワークスペースにクローンするGitリポジトリのURLを入力します。（例: https://github.com/user/repo.git）
Branch: チェックアウトするブランチ名またはタグ名を入力します。（例: main, master, v1.0.0）
